# Setup and Re-Authorization Guide

How to get this project running on a new machine, and how to reconnect the
external services it talks to. Commands are given for macOS/Linux (bash) and
Windows (PowerShell) where they differ.

## Runtime

- Python 3.10+
- `pip install -r requirements.txt`
- Google CLI tools (optional, only for Google Workspace agents):
  - `gcloud`
  - `gws` — `npm install -g @googleworkspace/cli`

## Skills

The `skills/gws-*` directories are generated by the `gws` CLI. See
`skills/NOTICE.md` for provenance and license.

Regenerate them instead of copying them between machines:

```bash
gws generate-skills --out ./skills
```

Optional companion skills referenced by some agent definitions
(`self-improving-agent`, `persona-sales-ops`, `persona-researcher`,
`persona-project-manager`) are not vendored here. Install them from your own
skill library, or remove the references from the relevant `agents/*` files.

## Project assets

Everything the project needs lives in the repository:

```
agents/  app/  data/  docs/memory/  skills/  scripts/  product-calculator/
```

No file outside the repository root is required.

## Re-authorizing Google

Credentials are never stored in the repository. Point the CLI at a file on the
machine:

```bash
# macOS / Linux
export GOOGLE_WORKSPACE_CLI_CREDENTIALS_FILE="$HOME/.config/gws/credentials.json"
gws auth login
```

```powershell
# Windows PowerShell
$env:GOOGLE_WORKSPACE_CLI_CREDENTIALS_FILE="$env:USERPROFILE\.config\gws\credentials.json"
gws auth login
```

Verify that Gmail and Drive are reachable before running the agents that use them:

```bash
gws gmail users messages list --params '{"userId":"me","maxResults":1}'
gws drive files list --params '{"pageSize":1}'
```

## Re-authorizing GitHub CLI

```bash
gh auth login          # macOS / Linux
```

```powershell
gh auth login          # Windows, or use the full path if gh is not on PATH
```

## Re-authorizing Notion

Reconnect Notion from the desktop integration or the configured MCP server, then
verify by reading a known page or database. There is no repository-side
configuration to change.

## Validation

```bash
python -m app.main
python -m pytest -q
```

## Notes

- Do not copy tokens or credential files between machines; re-authorize instead.
- Google-dependent agents skip themselves when no credentials are configured, so
  the rest of the system still runs.
- Workspace-specific learnings belong in `docs/memory/self_improving_agent.md`.

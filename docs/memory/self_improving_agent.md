# Self Improving Agent Memory

Use this file to preserve durable learnings for the foreign trade assistant only.

## Writing Rules

- Record only durable workflow learnings.
- Keep entries short and actionable.
- Do not store secrets, tokens, passwords, or raw credentials.
- Update existing rules instead of creating duplicates when possible.

## Entry Template

## YYYY-MM-DD - Short Title

- Context: what task or workflow triggered the learning
- Signal: what failed, what was corrected, or what succeeded unexpectedly
- Rule: the durable rule to apply next time
- Scope: foreign_trade_assistant
- Action: exact command, path, guardrail, or implementation note

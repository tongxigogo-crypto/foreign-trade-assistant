# Versioning Rule

- Current version: `v0.1.1-beta1-build10`
- Rule: every functional change or bugfix increments one small build number.
- Format: `v<major>.<minor>.<patch>-beta<phase>-build<nn>`

Examples:
- `build10` -> `build11` for next small iteration.
- Keep Win/mac on the same version tag for each release.

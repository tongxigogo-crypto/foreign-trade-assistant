# Skills 交接说明

以下是开发阶段常用技能（已复制对应目录）：

- `using-superpowers`：会话启动与技能调用规范。
- `brainstorming`：功能设计与需求拆解前置。
- `writing-plans`：复杂任务分解与执行计划。
- `test-driven-development`：先测后改，保证迭代稳定。
- `systematic-debugging`：异常排查闭环与定位流程。
- `verification-before-completion`：交付前强制验证。
- `requesting-code-review`：阶段性代码审查流程。
- `self-improving-agent`：失败模式沉淀与经验复用。

建议产品经理与技术负责人在继续开发前先统一这套执行流程，避免需求漂移与返工。

外贸助理 新手指导（首次使用）
版本：Beta 内测包

====================================
一、你只要记住 3 步
====================================
1) 启动服务：点击 One-click Start
2) 导入历史：点击 One-click Import
3) 处理任务：点击 Start Handling Tasks（进入网页看板）

说明：
- 桌面端负责“启动/导入/同步”
- 网页看板负责“任务/客户/事件处理”

====================================
二、Windows 首次使用（手把手）
====================================
1) 双击：安装依赖_windows.bat
2) 等待安装完成（窗口会提示下一步）
3) 双击：启动外贸助理桌面版_windows.bat
4) 进入桌面端后，按上面的 3 步操作

如果提示找不到 Python：
- 安装 Python 3.11+
- 安装时勾选 Add Python to PATH

====================================
三、Mac 首次使用（重点）
====================================
你会用到两个文件：
- 安装依赖_mac.command
- 启动外贸助理桌面版_mac.command

第一次建议按下面做：
1) 打开“终端”（Terminal）
2) 进入内测包目录，例如：
   cd ~/Desktop/外贸助理_mac_内测包
3) 给脚本执行权限：
   chmod +x 安装依赖_mac.command
   chmod +x 启动外贸助理桌面版_mac.command
4) 先运行安装：
   ./安装依赖_mac.command
5) 安装完成后再启动：
   ./启动外贸助理桌面版_mac.command

如果出现“Apple 无法验证开发者/可能有害软件”：
方法 A（推荐）
- 在 Finder 中按住 Control 点脚本 -> 选择“打开”
- 弹窗里再次点“打开”

方法 B（系统设置放行）
- 系统设置 -> 隐私与安全性
- 在页面底部找到被拦截提示，点“仍要打开”

方法 C（终端去除下载隔离标签，进阶）
- 在内测包目录执行：
  xattr -dr com.apple.quarantine .

====================================
四、浏览器扩展安装（一次即可）
====================================
1) 打开扩展页：
   - Chrome: chrome://extensions
   - Edge: edge://extensions
2) 开启“开发者模式”
3) 点击“加载已解压的扩展程序”
4) 选择内测包里的 extension 文件夹

====================================
五、最常见问题（小白快速排查）
====================================
问题 1：显示“服务器状态异常”
- 先回桌面端点击 One-click Start
- 5~10 秒后再点 Start Handling Tasks

问题 2：网页看板打不开
- 检查是否已点击 One-click Start
- 重启桌面端后再试一次

问题 3：导入后看不到变化
- 在网页看板点击刷新
- 检查导入目录是否选对

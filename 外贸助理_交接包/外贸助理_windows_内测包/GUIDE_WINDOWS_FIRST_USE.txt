外贸助理 Windows 版｜新手必读（首次安装与使用）

1) 安装（无需安装 Python）
- 先解压压缩包，不要在压缩包内直接运行。
- 双击 `Launch_InVault_Windows.bat`。
- 如遇 Windows 安全提示，点“更多信息 -> 仍要运行”。

2) 第一次使用（3步）
- 点击 `Start Work`。
- 点击 `Open Web Workbench`。
- 先执行一次全量导入，后续使用增量导入。

3) 更新
- 在桌面端点击 `One-click Update`，按提示切换新版。

4) 常见问题
- 网页看板打不开：先点 `Start Work` 再打开看板。
- 增量导入显示 0：确认新增文件已保存到导入目录后再重试。

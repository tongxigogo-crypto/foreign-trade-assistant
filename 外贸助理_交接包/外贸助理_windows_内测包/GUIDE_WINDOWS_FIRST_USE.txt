外贸助理 Windows 版｜新手必读（首次安装与使用）

一、你只需要看这一个文件
- 本目录里给新手使用的入口文件：
  - 启动外贸助理桌面版_windows.bat
- 其他文件（scripts/tests/requirements 等）是开发文件，新手可忽略。

二、第一次安装（约 1 分钟）
1) 先解压整个文件夹，不要在压缩包内直接运行。
2) 双击：启动外贸助理桌面版_windows.bat
3) 如果弹出 Windows 安全提示，选择“更多信息 -> 仍要运行”（内测阶段正常）。

三、第一次使用（3 步）
1) 在桌面端点击：One-click Start
2) 点击：Open Web Dashboard
3) 在网页看板处理任务、提醒、跟进

四、后续版本一键更新（桌面端内）
1) 点击：一键更新 / One-click Update
2) 系统会自动下载并准备新版
3) 按提示打开新版启动器即可

五、导入历史资料（建议做）
1) 在桌面端“历史导入”选择你的资料目录
2) 首次用全量导入，后续用增量导入

六、安全与数据说明
1) 你的敏感偏好（如底价规则、API Key）本地加密存储。
2) 换电脑导入备份后，敏感字段可能需要重新填写，这是安全设计。

七、遇到问题先看这里
1) 点启动没反应：关闭旧窗口后重试。
2) 网页看板打不开：先点 One-click Start，再点 Open Web Dashboard。
3) 仍异常：把问题截图发给我们，并说明你点的是哪个按钮。

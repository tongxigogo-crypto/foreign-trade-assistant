外贸助理 Windows 新手指导（首次安装与使用）

====================================
1) 先安装（必须先做）
====================================
1. 解压内测包到本地目录（例如桌面）。
2. 双击运行：安装依赖_windows.bat
3. 等待脚本安装完成（看到“完成/下一步”提示）。
4. 双击运行：启动外贸助理桌面版_windows.bat

如果提示找不到 Python：
- 安装 Python 3.11+
- 安装时勾选 Add Python to PATH

====================================
2) 安装后再使用（3 步）
====================================
1. 点击 One-click Start（启动服务）
2. 点击 One-click Import（导入历史资料）
3. 点击 Start Handling Tasks（进入网页看板处理任务）

====================================
3) 常见问题
====================================
问题：显示服务器状态异常
- 回到桌面端再点一次 One-click Start，等待 5~10 秒后重试。

问题：网页看板打不开
- 先确认已执行 One-click Start，再打开看板。

问题：导入后看不到数据
- 看板手动刷新一次，并确认导入目录选的是正确历史资料目录。

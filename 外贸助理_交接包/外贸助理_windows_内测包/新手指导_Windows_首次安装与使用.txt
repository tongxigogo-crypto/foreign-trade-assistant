外贸助理 Windows 新手指导（首次安装与使用）

1) 安装（无需安装 Python）
1. 下载并解压内测包到本地目录（例如桌面）。
2. 双击 `Launch_InVault_Windows.bat`。
3. 如果系统弹出安全提示，选择“更多信息 -> 仍要运行”（内测阶段正常）。

2) 第一次使用（3 步）
1. 点击 `Start Work`（一键启动）。
2. 点击 `Open Web Workbench`（打开网页看板）。
3. 在“历史导入”里先做一次全量导入，后续使用增量导入。

3) 后续更新
1. 桌面端点击 `One-click Update`。
2. 根据提示打开新版目录并继续使用。

4) 常见问题
1. 显示“服务器状态异常”：再次点击 `Start Work`，等待 5-10 秒后重试。
2. 网页看板打不开：先执行 `Start Work`，再点 `Open Web Workbench`。
3. 导入新增资料显示 0：确认新增文件确实已保存到所选目录，并使用“增量导入”。

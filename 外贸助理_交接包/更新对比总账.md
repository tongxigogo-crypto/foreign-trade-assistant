> 目的：每次更新后都能快速核对“是否丢功能/丢文件/丢平台同步”。

## 1. 固定开发目录（唯一）

- 主目录：`E:\CodexWorkspace\Playground-pm\外贸助理_交接包`
- Windows 包：`E:\CodexWorkspace\Playground-pm\外贸助理_交接包\外贸助理_windows_内测包`
- mac 包：`E:\CodexWorkspace\Playground-pm\外贸助理_交接包\外贸助理_mac_内测包`

## 2. 不可丢失的核心能力（基线）

1. 桌面端三栏主界面（工作台/中间对话/右侧看板）
2. API 设置（Provider/Key/Model/API URL）
3. API 对话发送（发送后清空输入框）
4. 连接测试按钮（明确返回：正常/Key 无效/网络异常/限流）
5. 历史导入：首批全量导入、导入新资料、批量导入邮件线程
6. 邮箱一键拉取（provider/account/password/days/max）
7. Extension 目录可加载（浏览器侧本地胶囊）
8. Win/Mac 同步：核心 app 与 tests 同步更新

## 4. 每次更新后的必做核对（5 分钟）

1. 代码状态：`git status --short`
2. 版本号：检查 `app/version.py`
3. 关键能力检索：
   - `rg -n "邮箱一键拉取|批量导入邮件线程|发送|连接测试|API URL" app/desktop_app.py`
4. 测试：
   - `python -m pytest -q tests/test_api_chat.py tests/test_config.py tests/test_startup_scripts.py`
5. Win/Mac 同步：
   - 对比 `外贸助理_windows_内测包/app` 与 `外贸助理_mac_内测包/app` 的同名核心文件

1. 任何功能删除前，必须先在本文件写“删除说明 + 原因 + 替代方案”。
